Wired into runner stages (below).

- Generation stages (`apps/api/src/generate.ts`, migration 0004): `keyframe` (fal Nano Banana 2, 9:16 1K), `scene_video` (fal Seedance 2.0 image-to-video from the keyframe's fal URL, 720p, 4–15 s) and `narration` (ElevenLabs per script line → `vo/L<n>.mp3` + `vo/words.json`), reading the plan from the script stage's `config.json` (`scenes[i].image_prompt/video_prompt/duration`, `script`, `voice_id`). The provider job id is saved in `stage_runs.external_id` before any wait, so a crash, lease loss or timeout re-attaches to the job instead of paying twice; only a new take clears it (a failed or unreadable job keeps its id, so a retry re-attaches instead of paying again); if the id cannot be recorded, the job is cancelled best-effort and the node parked; a re-attaching run skips the budget gate (its reservation already stands); narration reuses lines already spoken in the take; keyframe types are limited to png/jpeg/webp. Outputs download only from `data:` URLs or `https://*.fal.media` without redirects, capped at 300 MB. Narration estimates need the owner's plan rate in `projects.config.tts_cents_per_1k_chars` (no API setter yet, so narration fails closed for now). **Mocked** (9 tests on a fake fetch, mutation-checked); never called live.
- `characters` stage: one character reference sheet (fal Nano Banana 2, 16:9, front/side/back) from concept.json's characters and `projects.config.style`; keyframes then use `fal-ai/nano-banana-2/edit` with the sheet as reference (same price, checked 2026-11-05). Without a sheet, keyframes fall back to text-to-image. **Mocked** (1 test).
- Text stages (`apps/api/src/llm.ts`, `@feista/providers` `anthropicAdapter`, SDK `@anthropic-ai/sdk` 1.3.0): `concept` (original story checked against the owner's last 10 concept summaries, the project format's rules in the system prompt (see Format presets below), brief from `projects.config.brief`) and `script` (shot list + narration → `config.json` validated against the media worker's `load_plan`; `voice_id` from `projects.config.voice_id`). Claude Opus 5.5 with structured outputs, `fallbacks: "default"` (refusals re-run on Opus 5 / 4.8 server-side), effort high. Reserves the worst case (a billed mid-answer refusal plus the fallback attempt, 16k output each, input counted as UTF-8 bytes); reports the real cost only when Opus 5.5 itself answered (prices checked 2026-11-04). A paid answer that cannot be stored parks the node instead of paying again. Credential isolation: host pinned, the user's key sent as a per-request header (an `ANTHROPIC_CUSTOM_HEADERS` / `ANTHROPIC_API_KEY` / base URL on the host cannot replace it), and the runner drops all `ANTHROPIC_*` env vars at start. **Mocked** (6 tests, fixes mutation-checked); never called live.
- Format presets (`packages/core/src/formats.ts`, 2026-11-05): 16 animated-Short formats from the format research (animal stories, kids moral, horror, historical POV, myth retelling, "what if" 3D, whiteboard explainer, illustrated story narration, 3D meme dialogue, talking objects, meme animatic, micro-drama episode, recurring-cast action series, absurd hybrid creature, wordless satisfying loop, anime-style story). There is no channel-named format; animal stories is one generic preset and the default. A project picks one with `projects.config.format` (id) or sends a custom `{ base, name?, voice?, cast?, seconds?, lines?, beats?, rules?, style? }` (length- and range-checked). The preset sets the system prompt (beats, rules, kids/series flags, shared originality and YouTube 2026-07-16 inauthentic-content rules), the cast and line counts, the duration window (±5 s) and the default visual style. Voice modes: narrator (`voice_id`), dialogue (`projects.config.voices[i]` is the voice of the concept's i-th character; every speaker must be a concept character, matched without case, punctuation or bracketed asides → `line_voice` in config.json; concept cast is capped by the voices given; voice ids checked before anything is paid), inner (one first-person speaker), none (no lines: narration pays nothing and assembly mixes a silent voice bus). A scene count that cannot fit the format's length fails before the concept call. Narration speaks each line in its own voice and fails before paying if any line has none. **Mocked** (core 2 tests, API 6 new tests, media 1 new real-FFmpeg test; review fixes mutation-checked); prompts never run live.
- Clip Studio pipeline (2026-11-05): `CLIP_STAGES` in core (source → transcribe → highlights → clip_render × N → clip_qa × N → review → publish; N = the project's scene_count). A clip project needs `config.rights` = `own` or `licensed` at creation (400 otherwise), and every stage that reads the recording checks it again. `source` waits as awaiting_review until the recording sits at `<project>/source/g1/source.mp4` and the owner approves it. `transcribe` runs faster-whisper `small` (multilingual) locally. `highlights` asks the owner's Anthropic key for exactly N non-overlapping 15-60 s clips, best first, ranked on hook, completeness, emotion, coherence and value, never on shock. Transcript and brief are fenced as data, and long recordings over ~3 h are refused. `clip_render` cuts each pick to 1080×1920: the 16:9 frame sits fitted over a blurred copy of itself, with two-word captions (ASS override characters stripped) and two-pass loudnorm to −14 LUFS. `clip_qa` uses the delivery spec with a 3 s silence allowance. Project create now also takes a `config` object. **Tested locally**: real FFmpeg on a synthetic 16:9 recording through the queue, with a stubbed transcriber and a fake Anthropic API (API 5 tests, media 2 tests). faster-whisper itself is not run in CI.
- Clip Studio gaps: a user-set `tts_cents_per_1k_chars` of 0 makes narration estimates 0 (it is the owner's own plan rate on their own key, so the gate only protects them from themselves); no upload endpoint yet (it comes with S3 presigned uploads; tests write the file into storage directly); no face tracking (MediaPipe crop mode is the planned upgrade); no diarization; captions are the raw transcript words.
- Accepted gaps (text stages): a lost lease during the call lets a second runner pay again (needs a heartbeat failure first); an answer cut off at 16k tokens fails permanently after being billed (stream with a higher cap if it shows up); a fallback answer's real cost is not priced (the ceiling estimate stands).
- Accepted gaps: a polling run holds a worker slot while it waits (no `awaiting_provider` parking or webhooks yet); scene_video depends on fal keeping the keyframe URL alive.
