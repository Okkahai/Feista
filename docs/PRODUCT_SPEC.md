# Product spec (summary)

Feista = mobile control surface for two production engines whose work runs on the backend and survives the app closing.

- **Story Studio**: idea → script → scenes → characters → keyframes → scene video → narration → music → assembly + captions → media QA → metadata → user review → export/publish. Configurable duration, aspect, style, narrative style, voice, provider/model, quality, scene count, budget, output format. Per-scene retries.
- **Clip Studio**: authorized upload → audio → transcription (+diarization) → segment analysis → highlight ranking (hook, completeness, emotion, coherence, value; not sensationalism) → extraction → reframing → captions → QA → review → export. Managed mode (Vizard/OpusClip APIs) as an alternative.
- **Navigation**: Studio (home) · Create · Projects · Connections · Settings.
- **Connections**: BYOK providers, YouTube OAuth, status shown honestly.
- **Budget**: per-project and monthly caps, approval threshold, estimate vs reported spend.
- **Publishing**: manual export always; YouTube publish only after review and per the user's policy.
